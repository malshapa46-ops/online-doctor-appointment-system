# online-doctor-appointment-system
Online Doctor Appointment Booking System


This is an online doctor appointment booking system developed as a web-based project.

## Features

- Patient management
- Doctor management
- Doctor appointment booking
- Appointment management
- Doctor dashboard
- Patient dashboard
- Password reset
- Email functionality

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Project Description

This system allows patients to find doctors and manage doctor appointments through an online platform.
